# Airy Island Source Proposal Review Plan

For the later implementer: this is a review plan, not execution authority.
Goal: native editable island following the middle panel, less ground clutter.
Architecture: seven self-contained Blender Python modules plus one settings file.
Tech stack: bpy, mathutils and Python standard library only.
Spec: input commit 3928d49c29698672cd87585531479dfd113f80a2, GENERATOR_CONTRACT_BG.txt.

GLOBAL CONSTRAINTS
No old mesh/layout/camera or reference-image plane as terrain. No gnome, UI,
gameplay, sounds or animation. No network, subprocess, package installation or
purchases. New absolute output directory. Existing directories must be refused.
Stage A never imports or executes the source. Only text validation is performed.

REVIEW FOCUS
1. Existing output, relative path, loaded user scene: fail without modifying them.
2. Tight road bend: prevent intersecting rectangular boards, inspect outer seams.
3. Portrait crop: all crown and earth bounds fit at 432x960 and 864x1920.
4. Packed textures and colour: no missing PNG; verify save/reopen and GLB import.
5. Small decoration: exclusion zones and marker clearance remain visibly open.
