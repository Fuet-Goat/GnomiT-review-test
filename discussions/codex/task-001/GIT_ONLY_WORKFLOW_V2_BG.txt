Тази инструкция заменя предходните shared-v2 указания за ZIP/чат relay. Не променя grants, папки или игрови scope.

1. Общата цел и текущият етап са в SHARED_ART_ANIMATION_BRIEF_V2_BG.txt и SHARED_WORKBOARD_V2_BG.txt на codex/codex/task-001. Чети актуалния Git вариант при започване/подновяване, дори стар стартов prompt да е pinned към по-ранен commit.
2. GPT публикува каноничния master, сянка, metadata, сценен композит и ART_HANDOFF на codex/gpt/task-002. READY_FOR_ANIMATION е допустимо само при реални качени файлове и remote bytes/SHA-256 проверка.
3. Grok сам чете този клон и handoff от Git. Проверява реалните байтове, записва точния input commit, после публикува анимациите/metadata/ANIMATION_HANDOFF на codex/grok/task-002. Човекът не носи файловете или commit-а между чатове.
4. Всеки записва конкретния си статус, напредък, ограничения и действително изпълнени проверки в собствения REPORT. Запазва историята. Няма дублиращ commit при непроменен статус.
5. Codex чете двата клона и прави една обща проверка; статусът на workboard е snapshot, а истинският вход се определя по съществуващите handoff файлове и техните commit/hash.
6. Снимка в чат, списък с имена или локален ZIP не е Git предаване. Не искай от човека да сваля, прикачва, копира чужд отговор или прехвърля Base64 части.
7. При мрежов/DNS/tool blocker: запиши точната операция/грешка и статус BLOCKED в собствения Git REPORT, ако работещият Git конектор позволява това. Ако никакъв Git write не работи, кажи точно тази липса, без фиктивен commit/READY. За двоичните assets е необходима среда с файлов достъп и работещ git push; ограничението не се решава само с нов prompt. Не искай/споделяй пароли или токени.
8. Git е споделеното хранилище за задачи и резултати; този протокол НЕ е scheduler/runner за автоматично стартиране на GPT/Grok чат. Не обещавай, че commit ще събуди външен чат. При следващо активиране всеки продължава сам от Git, без препращане на материали.
9. Няма автоматичен merge, Godot execution, code/save/audio/private-project промени или нови агенти.
